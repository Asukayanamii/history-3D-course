## 一、项目概述

### 1.1 项目背景

本项目为 **大学生创新创业训练计划（大创）** 立项项目，后续目标为参加 **中国国际大学生创新大赛（互联网+）、"挑战杯"** 等全系列赛事。

当前阶段需要在 **本周末前** 产出一个可演示的 Demo，用于向指导老师确认项目方案、争取立项经费。Demo 不要求完整，能体现核心交互逻辑即可。

### 1.2 产品定位

**一句话定位：** 面向中学历史教师的三维历史时空交互课件——在可旋转的 3D 历史地图上，按时间轴推进重大事件，点击事件点进入沉浸式/全知视角的场景再现，辅助课堂教学。

**目标用户：** 高中历史教师（主要）、地理教师（同类延伸）。
**选材范围：** 统编教材《中外历史纲要（上、下）》中的重大事件。
**使用场景：** 课堂大屏授课、课前录屏预习、学生课后自主浏览。

### 1.3 与样板项目的关系

样板项目（长征 3D 交互课件）是"单线叙事+3D 地形"的成熟实现，本项目**借鉴其技术方案与交互范式**，但做两层扩展：

| 维度 | 样板项目（长征） | 本项目目标 |
|---|---|---|
| 地图主题 | 固定一段（长征路线） | **可切换历史时期**（五代十国、某战役、某改革……），同一套引擎适配不同主题 |
| 政权/疆域 | 现代地形底图，无政权边界 | **按所选时期显示真实疆域**（各国/各政权色块与标注），重点国家高亮 |
| 事件数量 | 12 个事件串联一条路线 | 从单事件起步，逐步扩展为多事件素材库 |
| 场景再现 | 事件卡片 + AI 插画 + 部分 VR | 事件卡片为基础，**3D 场景再现为高阶目标**（战争、朝堂等仿真） |

> 聊天记录原文："他这个确实不是我想要的，我想要的更多是这里面的东西"——指小红书视频中 3D 场景、动态路线、历史地图疆域这三块，而非单纯的 2D 插画卡片。

## 三、功能需求

### 3.1 Demo 阶段（本周内必须交付）

> 目标：跑通"3D 地图 → 单事件路线动画 → 事件卡片"这条主链路，能给老师演示。

#### F1. 3D 历史地图基础

- [ ] **F1.1** 使用 Three.js 渲染可旋转/缩放/平移的 3D 地形（参考样板项目，基于真实高程数据或简化平面地图）。
- [ ] **F1.2** 底图使用**指定历史时期的疆域图**（不是现代中国地图），政权边界与名称标注清晰可辨。
- [ ] **F1.3** 鼠标左键拖动旋转、滚轮缩放、右键平移（与样板一致）。
- [ ] **F1.4** 支持点击"回到全景"按钮复位视角。

#### F2. 单事件动态路线

- [ ] **F2.1** 选一个教材内的重大事件（如某战役、某改革历程），在地图上绘制一条路线。
- [ ] **F2.2** 路线以**动态生长**的方式逐段呈现（一条线顺着地图延伸前进），而非一次性画完。
- [ ] **F2.3** 路线上的关键节点（城市/地点）有地名标注。
- [ ] **F2.4** 支持键盘 `←` `→` 或翻页笔上下页控制路线前进/后退。

#### F3. 事件信息卡片

- [ ] **F3.1** 路线走到某个节点时，右侧滑出事件卡片。
- [ ] **F3.2** 卡片包含字段：事件标题、时间、地点、摘要、详细要点（3-5 条）。
- [ ] **F3.3** 卡片配一张配图（AI 生成或素材图）。
- [ ] **F3.4** 支持课堂提问：按 `Q` 弹出问题，再按 `Q` 揭晓答案（参考样板）。

#### F4. 页面基础

- [ ] **F4.1** 纯前端实现，**双击 index.html 即可在 Chrome/Edge 打开，无需联网、无需安装依赖**。
- [ ] **F4.2** 全屏 16:9 适配，适配教室大屏。
- [ ] **F4.3** 顶部标题栏（项目名 + 当前事件名）。

### 3.2 后续迭代（立项后逐步实现）

#### F5. 多时期/多事件素材库

- [ ] **F5.1** 历史时期切换器：下拉或侧边栏选择"五代十国""楚汉之争""抗日战争"等主题，地图与事件列表整体切换。
- [ ] **F5.2** 每个主题独立配置数据文件（类似样板的 `events.js`），新增主题只需加一个 JSON/JS 文件，不改引擎代码。
- [ ] **F5.3** 重点国家/政权高亮：教材要求掌握的对象用醒目色块或描边突出。

#### F6. 3D 场景再现（高阶目标，难点）

- [ ] **F6.1** 点击事件卡片中的"进入场景"按钮，从地图视角切入到该事件的 3D 场景。
- [ ] **F6.2** 场景形式优先级：全知视角俯瞰（容易实现）> 第一人称沉浸式 VR（难，作为长期目标）。
- [ ] **F6.3** 场景类型示例：战争态势图（双方军队推进）、朝堂/宫殿内辩论、重要建筑外观。
- [ ] **F6.4** 场景旁侧/下方有文字说明：时间、地点、主要人物、事件结果与影响。

#### F7. 课堂教学增强（参考样板已有功能）

- [ ] **F7.1** 时间轴：底部显示全部事件节点，点击跳转。
- [ ] **F7.2** 自动演示模式：按 `P` 自动逐站播放，适合录屏（URL 加 `?demo=1`）。
- [ ] **F7.3** 图层开关：路线、河流、地名、政权边界可独立开关。
- [ ] **F7.4** 音效：程序合成音效（行军、环境风声），按 `M` 开关，无版权问题。
- [ ] **F7.5** 海拔查询：单击地形显示海拔与经纬度（地形底图时）。

#### F8. 内容可配置

- [ ] **F8.1** 所有文字、路线坐标、镜头角度、图片路径集中在数据配置文件中，教师可自行用记事本修改。
- [ ] **F8.2** 图片放入 assets 文件夹即自动生效。

## 四、非功能需求

| 类别 | 要求 |
|---|---|
| 技术栈 | 原生 HTML + CSS + JavaScript + Three.js（与样板一致，不引入重型框架） |
| 运行环境 | Chrome / Edge 最新版，Windows / macOS 均可 |
| 离线可用 | 全部资源本地加载，不依赖 CDN 或网络 |
| 启动速度 | 双击后 3 秒内进入主界面 |
| 包体积 | Demo 阶段控制在 50MB 以内（样板为 14.4MB） |
| 分辨率 | 适配 1920×1080 教室大屏，向下兼容 |
| 兼容性 | 不要求支持移动端，但页面不应在小屏上崩溃 |
| 版权 | AI 生成素材标注"艺术复原示意"；历史地图注明来源；不商用 |

## 七、验收标准（Demo 阶段）

Demo 完成后，用以下清单逐条核对：

1. 双击 `index.html`，Chrome/Edge 直接打开，无报错、无需联网。
2. 3D 地图可旋转、缩放、平移，底图为**所选历史时期的疆域**（不是现代地图）。
3. 按 `→` 键，路线在地图上**动态延伸**，不是一次性出现。
4. 走到关键节点，右侧弹出事件卡片，含标题、时间、地点、摘要、配图。
5. 按 `Q` 弹出课堂提问，再按 `Q` 显示答案。
6. 整体观感与样板项目（长征课件）在同一水准，不要求美术精良，但交互逻辑完整。
7. 项目可被耿雨拿到指导老师面前，用 3-5 分钟讲清楚"这是一个可复用的历史 3D 课件平台"。
