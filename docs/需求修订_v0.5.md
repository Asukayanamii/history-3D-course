## 一、本轮两个改进

### 1. 除高平之战以外的战争事件场景：血条头标 + 占地网格

现状：
- `e06 高平之战` 是 `war` 省域兵棋，已有单位牌（兵力/士气条）和省份控制色块。
- 其他 war 事件是 `battle` 通用战场，只有单位名称标签和小人，没有持续可见的血条，也没有占地网格。

要求：
- 所有 `battle` 场景（不是只有 e06）：
  1. 每个单位上方有**血条头标**：单位名、兵/气两条、阵营色；随战斗推进变化。
  2. 战场地面有**占地网格**：单元格按当前控制方着色；单位推进/接战后控制格变化；可开关。
  3. 图例/说明明确“占地网格为战术示意，不是精确历史疆域或阵图”。
- `e06 war` 保持现有省份控制与单位牌，不要求再加一套网格；但不能因改动回归。
- 覆盖所有 war 事件：wudai e02/e04/e06/e07/e08；suitang e01/e02/e03/e04/e06；song e01/e02/e03。

实现建议（不强制）：
- `battle` 单位增加 `strength` / `morale`（0–100）；缺省 100。
- 用一个简单的确定性损耗模型：接战阶段按时间/兵种/城墙减伤扣血；溃退方在收束阶段掉到阈值以下；不使用随机数或固定 seed。
- 头标用 CanvasTexture + Sprite，显示单位名与两条 bar；颜色跟 `sides[].color`。
- 占地网格用覆盖纹理：与战场地形同几何的 Canvas 纹理；单元格中心归属由“最近单位 + 捕获半径”计算；每 0.2–0.3s 重绘。
- 网格默认 20×16 左右；初始按双方出生位置/河岸/城墙划分；中立格用灰色；图例说明。
- 战斗场景图层面板增加 `占地网格`、`单位`、`名字` 开关；不要复用 war 的省份/战线图层。
- 网格与头标都不能遮挡主要人物/单位；1920×1080 与 1366×768 可读。

### 2. 朝堂议论：讲话的小人要标注历史人物

现状：
- `e11 世宗改革` 的 `court` 场景有皇帝、文官、侍卫；右侧面板会显示“发言：角色名”，但 3D 小人身上没有名字。
- 角色数据目前是“宰相 / 户部官员 / 御史 / 禁军将领”等泛称，`phases[].speaker` 指向这些 id。

要求：
- 每个发言阶段，**3D 场景中正在讲话的小人上方出现历史人物名牌**：姓名 + 身份/官职（如“王溥 · 宰相”）。
- 非发言者的名牌可弱化或隐藏；发言者有高亮（名牌更亮/更大 + 脚下金色圆环）。
- 右侧“发言”栏使用同一姓名/身份，不能只写泛称。
- 更新 `e11` 的 `roles` 与 `phases`：
  - 柴荣（后周世宗）
  - 王溥（宰相）
  - 范质（宰相）
  - 李谷（大臣）
  - 赵匡胤（禁军将领）
  - 御史（台官，角色；如无法确认具体姓名就保留角色名，不要编造）
- 台词仍是教学情景复原，不写成史料原文；名牌只标身份，不做真实人物画像。
- 所有姓名/官职需要与 `docs/history/五代十国_资料包.md` 的 e11 资料一致；不确定的标“角色”或“待核订”。

## 二、数据契约增量

### 2.1 `battle` 可选字段

```js
battle: {
  preset: "field" | "siege" | "cavalry" | "ambush" | "river",
  terrain: "hebei" | "guanzhong" | "huainan" | "gaoping",
  grid: { cols: 20, rows: 16, captureRadius: 4.5 }, // 可选；缺省由引擎给默认
  sides: [{ id, name, color, short }]
}
```

`scene.units[]`（显式时）：

```js
{ side, type, count, label, start, end, moveAt, moveDur, wall, strength, morale }
```

### 2.2 `court` 角色字段

```js
roles: [
  { id: "chancellor", name: "王溥", rank: "宰相", side: "reform", pose: "listen" }
]
```

- `name` 用历史人物姓名；无法确认时用角色名并加 `roleOnly: true`（或明确写“角色”）。
- `phases[].speaker` 必须指向存在的 `roles[].id`。
- 名牌文本由 `name + " · " + rank` 生成。

## 三、验收

1. 所有 war 事件进入 `battle` 场景后，每个单位上方有血条头标（名字 + 兵/气），数值随阶段变化。
2. 战场地面有占地网格；双方推进时颜色变化；可在图层中关闭/打开。
3. e06 war 仍可正常推演（9 省、终局 7/1/1），不出现新网格/头标回归。
4. e11 court 每个阶段发言者头上有历史人物名牌；右侧“发言”同步；非发言者弱化。
5. 名牌/头标不遮挡主要人物；1920×1080、1366×768 可读。
6. `file://` 可用；无 console error；无外部网络请求。
7. `node --check` 通过；反复进出 battle/court 各 3 次无报错。
8. 文档更新：`course/README.md`、`docs/handoff/QA.md`、`docs/handoff/SCENE_SPEC_v0.4.md`（或新增 v0.5 增量说明）。
