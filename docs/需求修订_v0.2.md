## 一、修订结论

v0.1 已经覆盖了“可切换历史时期、动态路线、事件卡片、时间轴、自动演示、离线运行、来源标注”等大部分需求，但有三个实质缺口：

1. **真实历史疆域**：v0.1 写的是“历史时期疆域图”，但当前 Demo 用的是 `labelAt + radiusKm` 的示意色块，不是真实边界。聊天记录明确说“必须找公开的历史地图，根据当时真实疆域”。
2. **3D 场景再现**：聊天记录把它标为“难点！！！”，v0.1 只有 F6 概念条目，没有场景数据契约、场景清单、交互与验收；当前 Demo 只有禁用按钮。
3. **结构化场景文字**：聊天记录要求“时间、地点、主要人物、事件结果、影响”，v0.1 只在 F6.4 提了一句，事件数据里没有 `figures` / `result` / `impact` / `scene` 字段。

本修订把这三项补成可执行需求，并明确 Demo 与后续版本的边界。

## 二、已确定的产品决策

### 2.1 三个时期

| 主题 ID | 显示名 | Demo 内容 | 定位 |
|---|---|---|---|
| `wudai` | 五代十国 | 10 个事件（907–960），3 条路线 | **默认、重点演示** |
| `suitang` | 隋唐 | 6 个事件（安史之乱 755–763） | 薄主题，证明切换 |
| `song` | 宋朝 | 4 个事件（澶渊之盟 1004–1005） | 薄主题，证明切换 |

- 该决策来自用户 2026-10-23 的明确指示，替代 v0.1 第 8 节“具体选题待确认”。
- 新增时期仍按 v0.1 F5.2：只加 `data/theme.<id>.js` + `index.html` 一行 `<script>`，不改引擎。

### 2.2 真实历史疆域的分层验收

聊天记录要求“真实疆域”，但一天内拿到可商用的完整历史边界数据不现实。因此分两层：

| 层级 | 要求 | 本轮是否必须 |
|---|---|---|
| **Demo 层** | 用公开历史地图**参考**，为主要政权手写简化多边形；明确标“示意”；不复制图幅；不声称精确 | **必须**，至少 6 个主要政权 |
| **正式层（M3）** | 由历史组核对各政权边界，形成可追溯的简化多边形/底图；来源与许可逐项记录 | 立项后 |

**禁止**：把 `radiusKm` blob 说成“真实疆域”；把示意多边形说成“精确边界”。

### 2.3 3D 场景的分层验收

| 层级 | 要求 | 本轮是否必须 |
|---|---|---|
| **Demo 层** | 至少 1 个事件有“全知视角”低多边形场景；可进入/退出；有时间/地点/人物/结果/影响；有镜头、单位、战况推进 | **必须**，选 `wudai/e06 高平之战` |
| **M4 层** | 战争态势、朝堂辩论、建筑外观等 3–5 个场景；第一人称/VR 作为长期目标 | 立项后 |

- Demo 场景是**艺术复原示意**，不是历史影像；兵力、位置、旗帜均为示意。
- 其他事件保留“进入场景（待补）”禁用态，不误导为已实现。

### 2.4 教学目标

本课件的教学目标不是“讲完所有史实”，而是：

1. 让学生在地图上建立**时间—空间对应关系**（事件发生在哪里、势力如何分布）。
2. 通过动态路线理解**进程**（谁从哪里到哪里、先发生什么后发生什么）。
3. 通过一个全知场景建立**场景感**（战争态势/决策处境），但不替代史料阅读。
4. 用课堂提问把“看地图”转成“解释地图”。

课堂使用建议（3–5 分钟）：导入（看时期全图）→ 推进 2–3 个事件 → 进入 1 个场景 → 提问 → 回到时间轴总结。

## 三、修订后的功能需求

> 编号沿用 v0.1；新增项用 `F*.x` 补充。**加粗**为本轮必须实现。

### F1 · 3D 历史地图

- **F1.1** 可旋转/缩放/平移的 3D 沙盘；鼠标左键旋转、滚轮缩放、右键平移；`Home`/全景复位。
- **F1.2** 底图使用所选时期的政权布局，不是现代地图；政权名称、边界、重点政权清晰可辨。
- **F1.3** 保留。
- **F1.4** 保留。
- **F1.5（新）真实疆域分层**：
  - 五代十国：后周、南唐、吴越、后蜀、南汉、契丹（辽）至少 6 个主要政权用**简化多边形**；北汉、荆南、武平、定难军可用小多边形或 blob。
  - 隋唐/宋朝：本轮可继续用 blob，但必须标“示意”，并在交接文档列入替换清单。
  - 多边形必须：在 `map.bounds` 内、不自交、`status: "approx"`、`sourceNote` 说明参考来源与简化程度。
- **F1.6（新）地图快照提示**：`meta.mapSnapshot` 写明快照年份（五代十国为“约 955 年”）；图例或顶栏显示，避免学生误以为地图逐年变化。
- **F1.7（新）未单列势力说明**：`map.omitted` 列出未单独着色的政权/势力（如大理、吐蕃、河西、清源军），图例显示“未单列：……”。
- **F1.8（新）重点政权理由**：`regions[].highlightReason` 说明为什么重点（战争/改革/教材要求），图例显示“重点政权：后周（世宗改革与北伐）”。

### F2 · 动态路线

- **F2.1–F2.4** 保留。
- **F2.5（新）多路线**：一个主题支持 1–3 条路线；事件通过 `routeId + nodeId` 指向路线；切换事件时活动路线高亮，非活动路线压暗。
- **F2.6（新）路线与地图快照的差异提示**：路线可以进入“敌方”境内；事件卡片或图例提示“地图为时期快照，路线按事件时间推进”。

### F3 · 事件信息卡片

- **F3.1–F3.4** 保留。
- **F3.5（新）结构化人物/结果/影响**：事件数据增加：
  - `figures: string[]` 主要人物/角色；
  - `result: string` 结果；
  - `impact: string` 影响；
  - 卡片显示“主要人物”一行；结果/影响可在卡片详情或场景面板显示。
- **F3.6（新）场景入口**：有 `scene` 的事件显示可点击“进入场景”；没有则显示禁用“进入场景（待补）”，不误导。

### F4 · 页面基础

- **F4.1–F4.3** 保留；新增 `course/README.md`，写清打开方式、快捷键、换主题、替换资源。

### F5 · 多时期/多事件素材库

- **F5.1–F5.3** 保留。
- **F5.4（新）世界史主题**：引擎已支持任意 `bounds`，后续可加“二战战场进程”等世界史主题；本轮不做，但要在路线图中写明，避免把“素材库”说成只能做中国史。
- **F5.5（新）重点政权理由**：同 F1.8；图例不能只写“重点”，要写“为什么重点”。

### F6 · 3D 场景再现

- **F6.1** 点击有场景的事件 → 进入场景；`Esc`/返回按钮 → 回到地图原视角。
- **F6.2** 优先级：全知视角俯瞰 > 第一人称沉浸；本轮只做全知视角。
- **F6.3** 本轮场景：`wudai/e06 高平之战`（后周 vs 北汉/辽）；后续可做朝堂辩论、建筑外观。
- **F6.4** 场景旁侧/下方文字：时间、地点、主要人物、结果、影响；本轮必须有。
- **F6.5（新）场景数据契约**：`event.scene`：
  ```js
  scene: {
    type: "battlefield",          // battlefield | court | architecture
    title: "高平之战 · 全知视角",
    subtitle: "954年 · 后周 vs 北汉 / 辽",
    note: "低多边形艺术复原，不是历史影像",
    duration: 16,                  // 秒
    camera: { dist: 34, az: 35, polar: 58 },
    text: {
      time: "954年三月",
      place: "高平（今山西高平）",
      figures: ["柴荣（后周世宗）", "刘崇（北汉世祖）", "杨衮（辽将）"],
      result: "后周军获胜，北汉退守太原。",
      impact: "柴荣树立权威，整顿禁军，为后周改革与北伐奠定基础。"
    },
    phases: [
      { at: 0.0, label: "接战" },
      { at: 0.45, label: "相持" },
      { at: 0.75, label: "北汉军溃退" }
    ],
    units: [
      {
        id: "zhou", name: "后周军", color: "#d4553b", count: 120,
        formation: "infantry", start: [-12, 8], moveTo: [-2, 1],
        moveAt: 0.08, moveDur: 0.4,
        retreatTo: [-12, 8], retreatAt: 0.9, retreatDur: 0.1
      }
    ]
  }
  ```
- **F6.6（新）场景内交互**：拖动旋转、滚轮缩放、空格暂停/继续、`Esc` 返回；战况阶段与进度条。
- **F6.7（新）场景诚实性**：场景是低多边形/艺术复原示意；不得声称历史影像；不得编造具体兵力数字（如无来源）。

### F7 · 课堂教学增强

- **F7.1–F7.5** 保留（F7.5 海拔查询在无 DEM 的 Demo 中不适用，后续接 DEM 再启用）。
- **F7.6（新）场景入口快捷键**：`E` 进入/退出场景；`Space` 在场景内暂停/继续；帮助面板写清。

### F8 · 内容可配置

- **F8.1–F8.2** 保留。
- **F8.3（新）** `figures/result/impact/scene` 同样在数据文件中，教师可改；没有场景的事件不要写 `scene` 字段。

### F9 · 教学目标与课堂流程（新）

- **F9.1** 明确定义“基础空间观念”目标（见 2.4）。
- **F9.2** 帮助/README 给出 3–5 分钟课堂流程。
- **F9.3** 事件卡片保留课堂提问；场景面板不替代提问。

### F10 · 来源、许可与 AI 声明（新）

- **F10.1** 外部网站/地图/史料：使用或参考后必须在 `credits.sourceRecords` 与「来源与授权」中标注；无法确认许可就不用。
- **F10.2** 许可由实际取用者自行核实，不写成“待耿雨核实许可”；耿雨只负责史实审核。
- **F10.3** AI 插画/封面/场景：不逐张标来源；主页/页脚统一声明“AI 生成的艺术复原示意，不是历史影像”。
- **F10.4** 历史地图：只参考，不复制图幅；多边形/边界由历史组核对后标 `approx`/`reviewed`。

## 四、数据契约增量

### 4.1 `map` 新增

```js
map: {
  // ...既有字段
  mapSnapshot: "约 955 年（后周显德二年）",
  omitted: [
    { name: "大理", note: "约 955 年据云南；不在本课重点，未单列色块。" },
    { name: "吐蕃", note: "青藏高原；约 955 年吐蕃已分裂，未单列。" }
  ],
  regions: [
    {
      // ...既有字段
      highlightReason: "世宗改革与北伐，教材重点",
      polygon: [[104.6,35.2], [106.0,37.5], /* ... */]
    }
  ]
}
```

### 4.2 `events[]` 新增

```js
{
  // ...既有字段
  figures: ["柴荣（后周世宗）", "刘崇（北汉世祖）", "杨衮（辽将）"],
  result: "后周军获胜，北汉退守太原。",
  impact: "柴荣树立权威，整顿禁军，为后周改革与北伐奠定基础。",
  scene: { /* 见 F6.5；没有场景的事件不写 */ }
}
```

### 4.3 状态语义

- `polygon` 为 `approx`：根据公开历史地图简化，待历史组核对；不得当成精确边界。
- `scene` 存在：可进入；`scene` 缺失：禁用入口。
- `figures/result/impact` 缺失：卡片/场景显示“待补”，不编造。

## 五、本轮 Demo 验收清单

1. `course/index.html` 双击可开，无控制台报错，无外部网络请求。
2. 三个主题可切换；五代十国默认。

11. 场景明确标“低多边形艺术复原示意，不是历史影像”。
