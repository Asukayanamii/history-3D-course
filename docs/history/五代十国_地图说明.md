# 五代十国地图说明（快照约 955 年）

> **对应数据**：`course/data/theme.wudai.js`
> **地图范围**：`west 100, east 123, south 21, north 43`（等距圆柱投影）
> **快照年份**：约 955 年（后周显德二年）
> **状态**：`regions[].status = "approx"`；所有边界为 `labelAt + radiusKm` 生成的示意色块，不是精确疆域。
> **坐标说明**：事件、地名、路线节点坐标保留 2 位小数，取现代城市/关隘的大致位置；`labelAt` 与河流点为便于阅读保留 1–2 位小数。所有坐标都是**示意坐标，不是精确考古定位**。
> **许可**：本图没有复制任何外部地图图片、DEM 或底图瓦片；外部网站只作文字参考。详见 `docs/history/来源与许可核查.md`。

## 一、为什么选 955 年

1. **与主题定位一致**：Demo 的默认主题是“后周世宗与统一前夜”，955 年是柴荣即位后第一轮大规模对外用兵的年份——同年发动秦凤之战（至 956 年初结束）、开始三征南唐。
2. **政治地图相对稳定**：951 年后周建立、楚亡、北汉建立，到 955 年已经形成后周—北汉—南唐—吴越—后蜀—南汉—荆南—武平—定难军—辽并存的格局。
3. **能同时讲清南、北两条线**：955 年南唐仍据淮南，寿州、扬州在它手中，正好对应 `r-south` 的三征南唐；955 年辽仍据瀛、莫等州，瓦桥、益津、淤口三关也在辽手中，正好对应 959 年 `r-north` 的北伐目标。
4. **避免把不同年份混在一张图上**：如果选 958 年，南唐已失淮南；如果选 959 年，后周已收复三关；如果选 960 年，北宋已建立。955 年是一个能兼顾前因后果的折中点。

> **重要**：955 年的地图**不会逐年变化**。事件 e01–e04 发生在 907—947 年，早于快照；e05–e10 在 951—960 年之间。地图只提供“后周世宗时期”的空间背景，事件卡片负责讲时间变化。不要把 955 年的色块当成每个事件当年的疆域。

## 三、势力色块的设计

### 3.1 为什么全部用 `polygon: []` + `radiusKm`

- 五代十国的边界变化快、州县城头反复易手，现有公开地图也多属近似重建；在没有逐州核对之前，画 12—30 个点的多边形会制造“精确”的错觉。
- 契约允许 `polygon` 为空，由引擎按 `labelAt + radiusKm` 生成确定性 blob；这比编造精确边界更诚实。
- 本轮所有 `regions[].status` 都是 `approx`，不是 `reviewed`；`sourceNote` 都写明“示意色块，非精确边界”。
- 如果耿雨后续提供逐州核对的边界，或团队决定采用可许可的公开矢量数据，再把 `polygon` 填上，并把 `status` 改为 `reviewed`（只能由史实审核者改）。

### 3.3 几个容易画错的地方

1. **瀛州、莫州在 955 年属辽**：它们是燕云十六州的一部分，938 年交割后归辽；959 年柴荣北伐才收复。地图上 `qidan` 的色块应覆盖这一带，`houzhou` 不应把它画成自己的腹地。
2. **瓦桥、益津、淤口三关在 955 年属辽**：959 年才被后周收复。`r-north` 路线节点可以落在敌方境内，这是“北伐目标”，不是“后周领土”。
3. **淮南在 955 年属南唐**：寿州、扬州都在南唐手中；958 年南唐割江北十四州后，才归后周。`r-south` 是进攻路线，不是 955 年的边界。
4. **秦凤之战始于 955 年，至 956 年初结束**：后周显德二年攻后蜀，最终夺取秦、凤、阶、成四州。地图按战后结果示意（不是严格的 955 年末），但色块不逐州外扩；`places` 里的秦州只作点位提示。
5. **福州属吴越，泉漳属清源军**：闽亡后福建三分；不要整块画成南唐。
6. **定难军不是西夏**：1004 年（宋朝主题）西夏尚未建立；955 年更只是党项定难军。不要把 1038 年才出现的“西夏”标签贴到 955 年地图上。

## 八、如果后续要升级地图

1. **补多边形**：由耿雨逐州核对后，提供 12—30 个点、顺时针、不自交、在 bounds 内的简化多边形；把 `status` 改为 `reviewed`。
2. **补真实边界数据**：只能使用许可明确、允许二次分发的数据；记录作者、URL、许可、访问日期；不要用来源不明的地图图片。
3. **补 DEM/底图**：Demo 阶段不做；后续 M4 由实际取用者选产品、查许可、重新选范围（template 的 DEM 覆盖 100—118°E / 23.5—38.5°N，覆盖不了本主题 100—123°E / 21—43°N）。
4. **补清源军/大理/吐蕃/河西**：如果要单独着色，需要新增 `regionId`，并在 `assets.js`/文档中同步说明；不要为了“看起来完整”把不存在或已亡的政权画上去。
