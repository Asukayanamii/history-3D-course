## 本轮任务

### 任务 A：所有 `battle` 场景加“血条头标 + 占地网格”

范围：所有非 e06 的 war 事件（wudai e02/e04/e07/e08；suitang e01/e02/e03/e04/e06；song e01/e02/e03）。`e06 war` 保持原样，不要加第二套网格，也不能回归。

1. **血条头标**
   - 每个 `battle` 单位上方显示一个 CanvasTexture/Sprite：单位名 + 兵/气两条 bar + 阵营色。
   - 单位需要 `strength` / `morale`（0–100；缺省 100）。用简单、确定性、可复现的损耗模型：
     - 推进/接战阶段按时间、兵种、城墙/河岸减伤扣血；
     - 收束阶段溃退方掉到阈值以下；
     - 不要用 `Math.random()` 或未固定 seed。
   - 头标要随数值更新；不要遮挡人物；`depthTest:false`、合适的 `renderOrder`；1920/1366 可读。
   - 可保留现有单位名称标签，但避免与头标重复/重叠；建议用头标替换原轻量名称标签。

2. **占地网格**
   - 战场地面显示单元格控制网格（默认 20×16 左右；可在 `battle.grid` 里配 `cols/rows/captureRadius`）。
   - 初始按双方出生位置/河岸/城墙划分；单位推进/接战后，最近单位捕获半径内的格子变色；中立格灰色。
   - 推荐用“与战场地形同几何的 Canvas 覆盖纹理”绘制（参考 `scene.js` 的 `warBuildProvinceOverlay` / `paintWarProvinces`），不要用平面 GridHelper（会埋进地形）。
   - 每 0.2–0.3s 重绘；网格线用细线；颜色跟 `sides[].color`；不要把网格说成精确历史疆域。
   - `battle` 场景图层面板增加“占地网格 / 单位 / 名字”开关；`ui.openBattleScene` 目前隐藏了 `warLayersWrap`，需要为 battle 建一套图层（可新增 `ui.buildBattleLayers`，不要复用 war 的省份/战线图层）。
   - `S.setWarLayer` 支持 battle 的 `grid/units/labels`；`HS.ui.setWarLayerBox` 同步。

3. 数据/引擎
   - `battlePresetUnits` 给每个单位补 `strength/morale`（或 `battleBuild` 默认 100）。
   - `battleBuild` 创建网格覆盖层、单位头标；`battleUpdate` 更新数值/头标/网格；`battleStep` 只推进时间，不要把渲染逻辑塞进 step。
   - `S.restart` / `goToPhase` / `setTime` 重建 battle 时，头标/网格要同步重置。
   - 所有 battle 预设都要有网格：field/siege/cavalry/ambush/river。

### 任务 B：朝堂发言者加历史人物名牌

1. 更新 `course/data/theme.wudai.js#e11.scene.roles`：
   - `emperor`: 柴荣（后周世宗）
   - `chancellor`: 王溥（宰相）
   - `finance`: 范质（宰相）
   - `censor`: 李谷（大臣）
   - `general`: 赵匡胤（禁军将领）
   - `guard`: 侍卫（角色）
   - 如对某个具体姓名/官职不确定，保留角色名并标“角色/待核订”，不要编造。同步更新 `phases[].speaker` 和台词中对人物的称呼；右侧“发言”栏与 3D 名牌必须一致。
2. 在 `courtBuild` 给每个角色/皇帝的 3D 小人上方加名牌：
   - 文本：`姓名 · 官职`（如“王溥 · 宰相”）；皇帝“柴荣 · 后周世宗”。
   - 用 CanvasTexture + Sprite，深色圆角底 + 阵营/金色描边；`depthTest:false`，合适 `renderOrder`。
   - 平时所有名牌可弱化；当前 `phases[].speaker` 的名牌高亮（更亮/略大），非发言者透明度降低。
   - 发言者脚下加一个金色圆环/光环（`RingGeometry` 平铺地面），阶段切换时移动。
   - 皇帝在御座上的名牌高度要避开御座/屏风；侍卫可只显示弱化名牌或不显示。
   - 名牌要随角色缩放/位置正确；不要穿模，不要被屏风/横梁挡住。
3. `courtApplyPhase` 同时更新：角色姿态、右侧发言栏、3D 名牌、脚下光环。
4. 不自称“史料原文”；场景 note/README 仍写“人物称谓、台词为教学情景复原”。
