# 三维历史沙盘 · 三模型协作提示词包

这套文件用于把一个「可双击打开的 3D 历史沙盘 Demo」拆给三个模型协作完成。目标不是一次做到完美，而是让 PRD 里的每种效果在 Demo 中至少出现一次。

## 先定下的三件事

1. **时期**：五代十国（默认、重点演示）、隋唐（安史之乱）、宋朝（澶渊之盟）。
2. **形态**：`course/index.html` 双击离线运行；原生 HTML/CSS/JS + Three.js r147；无 CDN、无 npm、无后端。
3. **分工**：
   - **Claude**：搭建引擎、UI、交互、三个主题的占位数据，产出交接文档与资源替换清单。
   - **DeepSeek**：补全史料、地图势力范围、路线节点、事件文字、课堂问答、来源与图片脚本。
   - **GPT-Image2**：生成事件插画、封面、背景；统一「唐代壁画 × 历史油画」视觉。

## 推荐执行顺序

```text
Claude 第一轮
  └─ 交付：course/ 可运行 Demo（三个主题可切换，五代十国最完整）
  └─ 交付：docs/handoff/DEMO_HANDOFF.md、RESOURCE_REPLACEMENT.md、QA.md
        ↓
DeepSeek（可与 GPT-Image2 的风格测试并行）
  └─ 交付：三个主题的 theme.*.js + 史料资料包 + 地图说明 + 图片脚本
        ↓
GPT-Image2
  └─ 先做风格测试（五代十国封面 + 1 张事件图 + 1 张战争图）
  └─ 通过后批量生成；按 P0/P1/P2 优先级交付
        ↓
Claude 第二轮
  └─ 合并数据、接入图片、修版式、补来源面板、完整 QA
  └─ 交付：可汇报的 Demo + 更新后的交接文档
```

## 文件说明

| 文件 | 给谁 | 用途 |
|---|---|---|
| `00_协作总览与数据契约.md` | 所有人 | 统一文件结构、数据 schema、命名、状态、交接门禁、资源替换矩阵 |
| `01_Claude_沙盘骨架.md` | Claude | 第一轮搭 Demo；末尾附第二轮整合指令 |
| `02_DeepSeek_史料数据.md` | DeepSeek | 补三个时期的史料、地图、路线、问答、来源、图片脚本 |
| `03_GPT-Image2_美术资产.md` | GPT-Image2 | 生成插画/封面/背景；含主提示词、逐图提示词、验收标准 |

`00` 是共同契约，三个提示词都默认它会随仓库一起提供。**不要改字段名**；需要加字段时，先在 `00` 里登记，再同步三个模型。

## 怎么使用

- **Claude**：在能读写仓库的编码 Agent 里使用（Claude Code / Command Code / Cursor 等），把仓库根目录作为工作目录，粘贴 `01` 全文。它需要能读 `docs/` 和 `template/`。
- **DeepSeek**：优先用带联网能力的会话。能写文件就直接写指定路径；不能写文件就按文件名输出完整内容，由人保存。不要让它改引擎代码。
- **GPT-Image2**：能写文件就直接保存到 `course/assets/...` 并更新清单；只能出图就输出「文件名 + 英文提示词 + 中文说明」表格，由人保存图片。不要让它生成带文字的地图。

## 四条硬规则

1. **不照搬 template**：只借鉴「离线优先、数据与引擎分离、3D 地图 + HTML 标签、路线生长、事件卡片、键盘翻页、课堂提问、自动演示」这些思路；不复制 template 的代码、文字、路线、图片、CSS、配色和文件名。
2. **占位必须显式**：所有尚未核订的史料、边界、图片、来源，都要在数据里标 `placeholder` / `missing` / `needs-review`，并在交接文档里列出。不要用模糊措辞掩盖不确定性。
3. **来源标注分清两类**：用了别人的网站、地图、史料，必须在「来源与授权」里可追溯；AI 生成的插画/封面/背景不逐张标来源，只在主页/页脚统一声明一次。许可由实际取用资源的人自行核实，不要写成“待耿雨核实许可”。
4. **每个效果至少一次**：PRD 的 F1–F4 全做；F5 的主题切换做；F7 的时间轴、自动演示、图层、音效至少各做一次。F6 的 3D 场景只留禁用入口，不在本轮实现。

## 验收口径

- `course/index.html` 双击可开，Chrome/Edge 无报错、无网络请求。
- 五代十国主题可完整走完一条事件链；隋唐、宋朝可切换并至少走 3–4 个事件。
- 3D 地图可旋转/缩放/平移，显示时期势力范围而不是现代地图。
- 路线逐段生长，节点有地名，右侧事件卡片滑出，按 `Q` 出题/揭晓。
- 时间轴、自动演示、图层开关、静音、回到全景至少各可用一次。
- 所有占位资源在 `docs/handoff/RESOURCE_REPLACEMENT.md` 里有对应条目。
- 外部网站/地图/史料来源在「来源与授权」里可查；AI 图片只在主页/页脚统一声明，不逐张标注。
