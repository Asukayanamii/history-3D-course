## 一、硬性约束（不可违反）

### 1. 离线优先

- `course/index.html` 双击即可在 Chrome/Edge 打开；不需要本地服务器。
- 不用 `fetch` / `XMLHttpRequest` / ES Module / import map / npm / 构建步骤。

- 数据写成 `window.*` 全局变量；图片用 `<img>` 或 CSS `background-image`；WebGL 纹理用 Canvas 程序化生成或内联 data URI。
- 不做移动端，但小屏不能崩；主目标 1920×1080，16:9。

### 2. 只模仿思路，不照搬

**可以借鉴的工程思路**：

- 路线用曲线 + TubeGeometry + shader 进度生长。
- 镜头飞行、卡片打开时画面左移、翻页笔/键盘兼容。

**禁止照搬**：

## 四、技术方案

### 4.1 投影与沙盘

- 使用等距圆柱投影（equirect），不引入 GIS 库：
  `x = (lon - west) / (east - west) * W - W/2`
  `z = (north - lat) / (north - south) * H - H/2`
  `W = 100`，`H = W * (north - south) / (east - west) * cos(centerLat)`。
- 地图不是模板的真实 DEM 地形，而是一块**博物馆沙盘**：
  - 有厚度的圆角/不规则底座，轻微倒角；
  - 顶面用 Canvas 程序化生成沙粒、等高线、淡淡的水墨晕染；
  - 势力色块是半透明的“贴片”，略高于底座，带细描边；
  - 河流是细的浅青色管/线；
  - 可选：沿西/北边缘放几组低多边形山脊剪影，增加沙盘感；
  - 边缘用柔和渐隐/雾，避免硬切。
- 不要使用 template 的 `terrain.js`、真实 DEM、base64 地形纹理。

### 4.2 势力色块与标签

- `regions[].polygon` 有值时，用 `THREE.Shape` 从经纬度生成多边形，`ExtrudeGeometry` 或 `ShapeGeometry` 贴在沙盘顶面。
- `polygon` 为空时，用 `labelAt + radiusKm` 生成一个确定性的平滑 blob（12–18 个点），不要随机到每次刷新都不同。
- 边界用细管/线描边，颜色比填充略亮；避免 z-fighting（`depthWrite:false`、`renderOrder`）。
- 区域标签用 HTML 覆盖层，大号衬线字，低透明度；当前事件 `regionId` 对应的区域高亮，其余略暗。
- 地名标签用 HTML 覆盖层：首都/关卡/战场有不同的小图标或点样式；事件节点可点击。
- 标签每帧用 `Vector3.project(camera)` 更新位置；相机后方（`z > 1`）隐藏。
- 不要把中文标签烘焙进纹理。

### 4.3 路线

- 每条路线用一条平滑曲线穿过 `nodes`。建议实现一个累计弧长参数化的折线曲线，保证每个节点有稳定的 0–1 进度。
- 用 `TubeGeometry` + 自定义 `ShaderMaterial`：
  - `uProgress` 控制生长到哪；
  - `uTime` 控制流光/脉冲；
  - 路线头部有高光点；
  - 非活动路线降低透明度（0.18–0.25），活动路线高亮。
- 事件切换：
  - 同一路线：从当前进度补间到目标节点进度（0.8–1.2s）。
  - 换路线：旧路线淡出，新路线从 0 生长到目标节点，再打开卡片。
  - 允许后退（按 `←` 时进度反向补间）。
- 节点标签可点击，点击后跳到对应事件；共享节点只绑定第一个事件。
- 路线颜色由 `routes[].color` 决定；图例显示每条路线的名称/颜色。

### 4.4 相机

- `PerspectiveCamera(38, aspect, 0.1, 500)`。
- `OrbitControls`：左键旋转、滚轮缩放、右键平移、阻尼；限制 `minDistance`/`maxDistance`/`maxPolarAngle`。
- `flyTo({ lon, lat, dist, az, polar })`：球坐标插值，带一点“先拉远再落下”的抬升，0.9–1.4s，`easeInOutCubic`。
- 卡片打开时，用 `camera.setViewOffset()` 把画面中心向左偏移，避免右侧卡片遮住当前节点；卡片关闭时复位。
- `Home` 或「全景」回到 `meta.home`。
- 主题切换后重新计算相机初始位置。

### 4.5 UI

整体视觉：**博物馆展陈 × 古代舆图**，不要 template 的深褐纸张 + 红金配色。建议：

- 背景：墨青/深墨绿到黑的渐变，带轻微噪点和暗角。
- 沙盘：沙金/米黄，势力色块用石青、石绿、赭石、朱砂、藤黄等矿物色。
- 界面：窄边框、细线、半透明深色玻璃；标题用宋体/楷体系统字体，正文用宋体，控件用无衬线。
- 顶栏：左侧项目名「史境 · 三维历史沙盘」（占位名，可替换）+ 当前主题；中间三个时期标签；右侧工具（全景、图层、音效、演示、全屏、帮助）。
- 当前事件名：顶栏第二行或中间胶囊，随事件更新。
- 底部时间轴：一条细线 + 事件圆点 + 日期；当前事件高亮；点击跳转；左右两端是上一站/下一站。
- 右侧事件卡片：约 420px，滑入滑出；图片 16:9、日期/地点、标题、摘要、3–5 条要点、主要人物、按钮组（上一站/下一站、课堂提问、进入场景）。
- 「进入场景」只在 `ev.scene` 存在时可点击；没有场景时禁用并显示「（待补）」，不要统一禁用。
- 课堂提问：全屏遮罩，先出问题，再按 `Q`/点击揭晓答案；`Esc` 关闭。
- 来源与授权：顶栏/页脚入口；按主题列出外部网站/地图参考（`sourceRecords`）、事件史料来源、Three.js MIT。**不要**为每张 AI 图单列来源。
- 主页/首屏和主界面页脚各有一句统一声明：历史地图为示意性简化；外部地图参考见「来源与授权」；插画/封面为 AI 生成的艺术复原示意。
- 图层：路线、势力、河流、地名、事件标签、自动旋转（可选）独立开关。
- 帮助：鼠标、键盘、翻页笔、主题切换、快捷键。
- 首屏：简短标题/副标题/「开始探索」；`?nointro=1` 跳过。
- 小屏：卡片改为底部抽屉或全宽，不能溢出。

### 4.6 交互与快捷键

- `→` / `PageDown` / `Space`：下一站
- `←` / `PageUp` / `Backspace`：上一站
- `Home`：回到全景
- `Q`：课堂提问 / 揭晓答案
- `P`：自动演示开/关
- `L`：图层面板
- `M`：静音/恢复
- `F`：全屏
- `1` / `2` / `3`：切换五代十国/隋唐/宋朝
- `Esc`：关闭弹窗/卡片/退出全屏
- 所有快捷键要 `preventDefault`，避免页面滚动；输入框聚焦时不触发（本 Demo 没有输入框，但保留判断）。

### 4.7 自动演示

- `?demo=1`：首屏后 1.2s 开始，按事件顺序逐站播放。
- `?dwell=8000`：每站停留毫秒数，默认 6800。
- `?nointro=1`：跳过首屏。
- `P` 可随时暂停/继续；用户拖动/点击地图时自动暂停，再按 `P` 继续。
- 演示模式显示一个小角标；结束时显示「演示结束」，不无限循环。

### 4.8 主题切换

- 顶栏三个标签；点击 `switchTheme(id)`。
- 切换流程：关闭弹窗/卡片 → 0.3s 淡出 → dispose 旧场景 → 重建 → 相机飞到 `meta.home` → 延迟 0.3s 打开 `defaultEventId` 卡片。
- 必须 dispose：几何体、材质、纹理、事件监听、定时器；避免切换多次后内存上涨。
- 主题切换不刷新页面；不依赖 `history.replaceState`。
- URL 首次加载支持 `?theme=wudai`、`?event=e05`；非法值回退。

### 4.9 音效（可选但建议）

- 用 Web Audio API 实时合成，不加载音频文件：
  - 进入/切换主题：低频铺底 + 轻风声；
  - 路线推进：短促的木质/鼓点；
  - 卡片打开：一声轻响；
  - 静音按钮 `M`。
- 必须等用户第一次交互后再启动 AudioContext（浏览器自动播放策略）。
- 不做背景音乐，避免版权。

### 4.10 调试/录屏钩子

实现 `window.HISTORY_APP`，并挂 `window.__sandbox`：

```js
window.__sandbox = window.HISTORY_APP;
```

至少支持：`switchTheme`、`goTo`、`next`、`prev`、`play`、`pause`、`goHome`、`state`、`screenOf`、`isFlying`、`enterScene`、`exitScene`、`toggleScene`。这些钩子用于自测和后续录屏，不影响正常用户。

### 4.11 3D 全知场景（v0.2，至少 1 个）

- 用独立的 `js/scene.js` + `#sceneCanvas` + 独立 `WebGLRenderer`，不要干扰主沙盘。
- 当前只实现 `scene.type: "battlefield"`；`court/architecture` 返回 false，不要假装已实现。

- 场景内容：
  - 低多边形地面/山脊/军阵/旗帜；全部程序化几何体 + Canvas 纹理，不加载图片。
  - `units` 的 `start/moveTo/retreatTo` 是场景局部坐标，不是经纬度；按 `moveAt/moveDur/retreatAt/retreatDur` 插值。
  - 战况阶段 `phases` + 进度条；镜头可旋转/缩放；默认缓慢自动旋转，用户操作后停止。
  - 右侧面板显示时间、地点、主要人物、结果、影响；明确「低多边形艺术复原，不是历史影像」。
